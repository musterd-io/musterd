# musterd v0.7.1

Upgrade if you run `@musterd/cli` 0.7.0 or earlier. This release fixes
[GHSA-jw8q-rc2q-m45q](https://github.com/musterd-io/musterd/security/advisories/GHSA-jw8q-rc2q-m45q).

## What's new

- **Security.** [GHSA-jw8q-rc2q-m45q](https://github.com/musterd-io/musterd/security/advisories/GHSA-jw8q-rc2q-m45q) covers `@musterd/cli` through 0.7.0. From 0.7.1, a toolkit MCP server is provisioned when an admin granted that exact command or URL in `seat_tools.servers`, or when the definition matches a built-in toolkit.
- **Seat tools stay on the declared set.** Each harness reports how far it can isolate tools. A tool the seat did not declare stays closed. Set the grant with `musterd team policy --seat-tools`.
- **Passkeys.** Revoke one from `/live` settings. Approve a new one from the phone. An admin can vouch for the enrollment from `/live`. A passkey records the origin it signs on. A phone key ends when its pairing ends.
- **The phone app shows the team.** Three tabs: Now, Work, and You. The roster matches `/live`, including who needs you. Quick actions run on that seat. (iOS, TestFlight.)
- **Seats on shift.** Inside working hours a seat can recommend work, claim a lane, or start itself. Shift hours are on `/live`. `musterd shift` reads them.
- **A deep inbox stays fast.** Rows nobody owed you are counted and skipped. Inbox, nudge, and wake reads seek their window.
- **A second machine joins the hub.** A joiner's `/live` opens on the hub's https address. That machine's service seat talks to the hub. `musterd node repoint` and `musterd node relabel` move a node.
- **Cloud seats sleep.** When a hub maps seats to Fly machines, it starts a machine when a wake is due and stops it once the seat is idle.
- **The office on `/live`.** A goal bell when a lane is done, signs you can read, and a view outside the windows that follows the clock and the weather.
- **Polls on a Twitch stream.** Start, end, and cancel a poll from `/live` or the phone. The commands are `musterd poll start`, `musterd poll end`, `musterd poll cancel`, and `musterd poll status`.
- **A withdrawn question leaves the phone.** A late answer is refused.
- **Muse hears the team mid-task.** Grok detection reads `GROK_HOME`.
- **Create a team from the console.** The form is on `/account`. The new host token is shown once.

Full list: [v0.7.0...v0.7.1](https://github.com/musterd-io/musterd/compare/v0.7.0...v0.7.1)
