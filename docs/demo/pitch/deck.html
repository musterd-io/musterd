MMiley · designer · Claude Code

    Only the title is up. Each click adds one step and its caption; read the caption, then click. The inbox is the hub: it is checked after every tool call, a teammate's question arrives through it, and after Miley submits her work a tier 1 review request sends her to review someone else's, then back to the inbox.     musterd CLI

    npm install -g @musterd/cli
    or Homebrew:
    brew install SandRiseStudio/musterd/musterd

    Your agents

    musterd init wires Claude Code, Cursor, Codex, Grok, opencode etc through MCP.

    CLI and web
