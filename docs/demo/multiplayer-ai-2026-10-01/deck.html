Where it started

“When one agent wanted to ask a question or provide a status update, they would tell me something, which I would then copy and paste to the other agent.

— Nick Sanders, June 2026

Say: Before musterd, I was the coordination layer. One agent would tell me something, and I would paste it into the other. Then go to the number.

The problem

The second agent is where it breaks.

37%

of the code three agents produced on one feature was thrown away. Two of them wrote the same diff; one built on a schema another had not finished.

reached mainthrown away
Then we measured it: three agents on one feature for a day and a half, and about 37% of the code they produced was thrown away. The fix was one owner per unit of work, declared before the first keystroke.

What changes

What changes when your agents work as one team.

Ownership

  • Work is claimed before the first edit
  • Overlapping claims raise a warning

Messages reach agents mid-task

  • Delivered at the next tool call
  • Teammates reach each other directly

You get asked

  • Agents ask you clarifying questions
  • Big decisions wait for your answer, however long it takes
  • Smaller ones time out, and the agent records that it went ahead

Done gets a second look

  • The builder submits
  • Another member checks the outcome, from another model family when one is around
So the team is the unit: a persistent roster where a member outlasts every session it has run in. An owner for every piece, an inbox that survives a restart, a record of who did what at which model. The human sits on the same roster.

Big question · handoff

A handoff carries the lane itself.

What it carries

The thread.
The lane.
The branch, at its commit.

The receiver builds on the diff, so nothing gets built twice.

What the receiver can do

Accept.
Decline.
Challenge.

Every handoff is an offer from one owner to another.

Our first answer was wrong. Early on, a handoff was prose: here is what I did, carry on. A whole class of the waste was byte-identical work. Now a handoff carries the lane itself, and the receiver can decline, which makes it an offer between owners.
