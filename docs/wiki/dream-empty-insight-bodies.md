# Dream insights with empty bodies

Insights could be stored with an empty body while truncated was false, and stay that way overnight — until 2026-10-15, when the server, the MCP tool and the CLI began refusing empty bodies (lane `01M50C7QWJ`). The historical empty rows named here were not backfilled.
