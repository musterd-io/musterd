# Idle-at-prompt wake — Implementation Plan (increments 1–2)

> **For agentic workers:** REQUIRED SUB-SKILL: use `superpowers:executing-plans` task by task. The
> workspace contract forbids writing subagents (AGENTS.md hard rule 8): the owning seat implements
> every task itself. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code seat whose session sits idle at its prompt takes a turn within 60 s of a
teammate directing a ringable act at it. Every switch can turn this off, and every inject leaves an
audit row.

**Architecture:** The daemon decides *what* rings. A new `seam=idle` mode of
`GET /inbox/interrupt-check` adds plain directed `ask`/`request_help`/`handoff` to today's live set
and applies the team and seat switches. The MCP adapter decides *when*: it already receives a
`deliver` frame for every directed act. A pure decider combines that frame with local idle evidence
(tool calls in flight, turn markers, transcript mtime) and the guards. When the session is idle, the
adapter asks the daemon for the line and posts it to Claude Code's inbox socket. The adapter reports
each outcome on a new audit route and carries `hearing` on its heartbeat.

**Tech stack:** TypeScript, zod, vitest, `node:net` (unix socket). No new runtime dependency.

**Spec:** [`docs/superpowers/specs/2026-10-07-idle-wake-design.md`](../specs/2026-10-07-idle-wake-design.md)

## Corrections to the spec, found while planning (the ADR records them)

1. **`rail` is taken.** `interrupt-check` already reads `?rail=<harness id>` and audits it as
   `detail.rail` (ADR 423). The idle seam is therefore a separate parameter, `?seam=idle`, audited as
   `detail.seam: 'idle'`, with `rail` still naming the harness. Spec §1 and §7 read `rail: 'idle'`;
   the ADR uses `seam`.
2. **No `.musterd/session/` directory and no token on disk.** The
   `CLAUDE_CODE_MESSAGING_SOCKET`/`_TOKEN` variables are in the environment of every child of
   `claude` (confirmed 2026-10-10 on 2.1.296 from a Bash child of this session; the MCP stdio server
   is a sibling child). The adapter reads them from its own `process.env`. The only local state is
   `.musterd/idle-wake.json`, which holds turn markers and the session switch, never a secret. The
   existing trace hook already fires on `UserPromptSubmit` and `Stop`
   (`packages/cli/src/onboard/harnesses/claudeCode.ts:396-403`), so it writes the markers and no new
   hook event is installed.
3. **The inbox socket's wire format.** The public docs
   (code.claude.com/docs/en/cross-session-messaging) leave the framing undocumented. Claude Code
   2.1.296 prints it in its own `[uds-messaging]` debug help: newline-delimited JSON over the unix
   socket, first `{"type":"auth","token":"…"}`, then
   `{"type":"user","message":{"role":"user","content":"…"}}`. A connection that sends no complete
   line within 30 s is closed. Task 7's canary is the measurement that confirms it.
4. **`hearing` is an audit row in this increment, not a presence column.** Roster display is
   increment 5. Here the daemon accepts `hearing` on the heartbeat and writes `presence.hearing` on
   each change. No migration.

## Global constraints

- Protocol schema changes land only after the ADR (Task 1) is merged (hard rule 1).
- The line is daemon-composed from structured fields; the adapter never composes or edits it
  (ADR 088 §4, ADR 128).
- The adapter never logs, persists or sends `CLAUDE_CODE_MESSAGING_TOKEN` (hard rule 5).
- Injecting moves neither presence nor the inbox cursor (spec §2 "Neutrality"). The audit route
  carries `x-musterd-no-touch: 1`.
- Defaults: team `idle_wake` **true**. Idle = 0 tool calls in flight, the last `Stop` marker is
  newer than the last `UserPromptSubmit` marker, and the transcript has been quiet ≥ 15 s.
  Coalescing window 5 s. Keyboard guard 30 s after the last `UserPromptSubmit`. Caps: 3 per hour per
  sender and 6 per hour per session. Deaf flip: no transcript movement within 60 s of an ok inject.
- Every failure path fails open to *no inject*. The boundary seams still carry the act, and nothing
  here may fail a tool call.
- Shared laptop: run at most **one targeted test file** locally (check `uptime` first); the full
  suite runs in CI. Local gates before push: `pnpm typecheck && pnpm lint && pnpm format:check`.
- Every new source file gets a described line in its package's `## File tree` block in
  `docs/architecture/0N-*.md` (`arch-trees:check`).
- Commits end with `Co-authored-by: izzo <izzo@revive.musterd>`.

## Review focus

1. **A burst from one sender** (a steer and two asks within 2 s) must produce one inject, not
   three. Pinned in Task 6 (`coalesces a burst`).
2. **A human who typed a prompt 10 s ago** must never get an injected turn on top of it. Pinned in
   Task 6 (`keyboard guard`).
3. **Two idle seats steering each other** stop after 3 injects per hour per sender. Pinned in Task 6
   (`per-sender cap`).
4. **An act already answered** before the coalescing window closes injects nothing, because the
   daemon re-checks discharge. Pinned in Task 3 (`seam=idle silent once discharged`).
5. **The socket is missing or refuses the post** (bare mode, an old Claude Code, a refused auth). The
   session flips deaf with a reason and stops trying until a probe succeeds. Pinned in Task 5
   (`refused`) and Task 6 (`deaf flip`).

```ts
/** The acts that ring an idle session when directed to its seat (idle-wake spec §1, ADR NNN). */
const IDLE_RINGS = new Set(['steer', 'ask', 'request_help', 'handoff']);

/** The envelope fields the idle rule reads — structural, so `/live` and the adapter can call it. */
export interface IdleRingInput {
  act: string;
  from: string;
  to: { kind: string; name?: string };
  meta?: Record<string, unknown> | null;
  thread?: string | null;
}

/**
 * Does this act ring `seat`'s idle session (ADR NNN §1)? Directed — to the seat, or an eligible set
 * naming it — and either flagged urgent or one of the four acts that ask the seat to do something.
 * A team-addressed act never rings an idle session; huddle turns ring through the live set's
 * membership rule on the daemon, which an envelope alone cannot decide.
 */
export function idleRingable(env: IdleRingInput, seat: string): boolean {
  if (env.from === seat) return false;
  const named = eligibleOf(env.meta);
  const directed = named ? named.includes(seat) : env.to.kind === 'member' && env.to.name === seat;
  if (!directed) return false;
  if (env.meta?.['urgent'] === true) return true;
  return IDLE_RINGS.has(env.act);
}

/** The adapter's cheap pre-filter: {@link idleRingable}, or any threaded act (a possible huddle
 *  turn) — the daemon's `seam=idle` read is the authority for both. */
export function idleMayRing(env: IdleRingInput, seat: string): boolean {
  return idleRingable(env, seat) || (env.from !== seat && env.thread != null);
}
```

```ts
import { z } from 'zod';

/**
 * Idle-at-prompt wake (ADR NNN). The daemon decides what rings (`seam=idle` on interrupt-check);
 * the adapter decides when, from evidence only the session's machine has. These are the shapes the
 * two halves share, plus the one local file the hooks and the adapter share.
 */

/** Which seam asked interrupt-check. `rail` stays the harness id (ADR 423). */
export const InterruptSeamSchema = z.enum(['boundary', 'idle']);
export type InterruptSeam = z.infer<typeof InterruptSeamSchema>;

/** Can this session be pushed while idle? `deaf` carries a reason. */
export const HearingSchema = z.enum(['idle', 'deaf']);
export type Hearing = z.infer<typeof HearingSchema>;
export const HearingReasonSchema = z.string().min(1).max(80);

/** The adapter's outcome report (`POST …/inbox/idle-wake`). Structured fields only — never the line. */
export const IdleWakeReportSchema = z
  .object({
    act: z.string().min(1).max(40),
    outcome: z.enum(['injected', 'failed', 'capped']),
    harness: z.string().min(1).max(40),
    reason: HearingReasonSchema.optional(),
    cap: z.enum(['sender', 'session']).optional(),
  })
  .strict();
export type IdleWakeReport = z.infer<typeof IdleWakeReportSchema>;

/** `.musterd/idle-wake.json` — turn markers (hook-written) and the session switch. No secrets. */
export const IdleWakeStateSchema = z.object({
  session_id: z.string().max(120).optional(),
  last_prompt_at: z.number().int().optional(),
  last_stop_at: z.number().int().optional(),
  switch: z.enum(['on', 'off']).optional(),
});
export type IdleWakeState = z.infer<typeof IdleWakeStateSchema>;

export const IDLE_QUIET_MS = 15_000;
export const IDLE_COALESCE_MS = 5_000;
export const IDLE_KEYBOARD_GUARD_MS = 30_000;
export const IDLE_SENDER_CAP_PER_HOUR = 3;
export const IDLE_SESSION_CAP_PER_HOUR = 6;
export const IDLE_DEAF_AFTER_MS = 60_000;
```

```ts
import { readFileSync, renameSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { type IdleWakeState, IdleWakeStateSchema } from '@musterd/protocol';

/**
 * `.musterd/idle-wake.json` (ADR NNN) — the one file the turn hooks and the MCP adapter share:
 * when the human last prompted, when the last turn ended, and this workspace's session switch.
 * Never a secret. Fail-open on read: an unreadable file is "no evidence", never an error.
 */
export const IDLE_WAKE_FILE = 'idle-wake.json';

export function readIdleWakeState(dir: string): IdleWakeState {
  try {
    const parsed = IdleWakeStateSchema.safeParse(
      JSON.parse(readFileSync(join(dir, '.musterd', IDLE_WAKE_FILE), 'utf8')),
    );
    return parsed.success ? parsed.data : {};
  } catch {
    return {};
  }
}

/** Merge a patch. A new `session_id` drops the previous session's markers; the switch survives. */
export function writeIdleWakeState(dir: string, patch: Partial<IdleWakeState>): void {
  const prev = readIdleWakeState(dir);
  const base: IdleWakeState =
    patch.session_id !== undefined && patch.session_id !== prev.session_id
      ? { ...(prev.switch ? { switch: prev.switch } : {}) }
      : prev;
  const next = { ...base, ...patch };
  const path = join(dir, '.musterd', IDLE_WAKE_FILE);
  const tmp = `${path}.${process.pid}.tmp`;
  writeFileSync(tmp, JSON.stringify(next), { mode: 0o600 });
  renameSync(tmp, path);
}
```

```ts
import { connect } from 'node:net';
import type { InjectAdapter, InjectResult } from './inject.js';

/**
 * Claude Code's inbox socket (v2.1.224+; ADR NNN §4). "When the receiving session is idle, Claude
 * Code starts a new turn with the message" (code.claude.com/docs/en/cross-session-messaging). The
 * framing is undocumented publicly; Claude Code prints it in its own `[uds-messaging]` debug help
 * (2.1.296): NDJSON, an optional `{"type":"auth"}` first line, then a `{"type":"user"}` message.
 *
 * The variables are read from THIS process's environment — the adapter is a child of `claude` like
 * any hook. The token is never logged, persisted, or echoed in a reason (hard rule 5).
 */
const CONNECT_TIMEOUT_MS = 5_000;

export function claudeInbox(env: NodeJS.ProcessEnv): InjectAdapter {
  const socketPath = env['CLAUDE_CODE_MESSAGING_SOCKET'];
  const token = env['CLAUDE_CODE_MESSAGING_TOKEN'];
  return {
    harness: 'claude-code',
    probe: () =>
      socketPath ? { ready: true } : { ready: false, reason: 'no-messaging-socket' },
    inject: (line) =>
      new Promise<InjectResult>((resolve) => {
        if (!socketPath) return resolve({ ok: false, reason: 'no-messaging-socket' });
        let settled = false;
        const done = (r: InjectResult) => {
          if (settled) return;
          settled = true;
          clearTimeout(timer);
          sock.destroy();
          resolve(r);
        };
        const sock = connect(socketPath);
        const timer = setTimeout(() => done({ ok: false, reason: 'timeout' }), CONNECT_TIMEOUT_MS);
        sock.on('error', (err: NodeJS.ErrnoException) =>
          done({ ok: false, reason: `connect:${err.code ?? 'error'}` }),
        );
        sock.on('connect', () => {
          const lines =
            (token ? `${JSON.stringify({ type: 'auth', token })}\n` : '') +
            `${JSON.stringify({ type: 'user', message: { role: 'user', content: line } })}\n`;
          sock.end(lines, () => done({ ok: true }));
        });
      }),
  };
}
```

```ts
import {
  type Envelope, type Hearing, IDLE_COALESCE_MS, IDLE_DEAF_AFTER_MS, IDLE_KEYBOARD_GUARD_MS,
  IDLE_QUIET_MS, IDLE_SENDER_CAP_PER_HOUR, IDLE_SESSION_CAP_PER_HOUR, type IdleWakeReport,
  type IdleWakeState, idleMayRing,
} from '@musterd/protocol';
import type { InjectAdapter } from './inject.js';

const HOUR = 3_600_000;

/**
 * The idle-wake core (ADR NNN §2–3). Pure over its deps so every guard is testable on a fake clock:
 * the daemon decides WHAT rings (`seam=idle`), this decides WHEN — from evidence only this machine
 * has. Every failure is silence: the boundary seams still carry the act at the next tool call.
 */
export class IdleWake {
  private timer: { cancel(): void } | null = null;
  private pendingFrom = new Set<string>();
  private readonly injects: { at: number; from: string }[] = [];
  private deaf: string | null = null;
  private watch: { cancel(): void } | null = null;
  private readonly now: () => number;
  private readonly setTimer: NonNullable<IdleWakeDeps['setTimer']>;

  constructor(private readonly deps: IdleWakeDeps) {
    this.now = deps.now ?? Date.now;
    this.setTimer =
      deps.setTimer ??
      ((fn, ms) => {
        const h = setTimeout(fn, ms);
        h.unref?.();
        return { cancel: () => clearTimeout(h) };
      });
  }

  onDeliver(env: Envelope): void {
    const seat = this.deps.seat();
    if (!seat || !idleMayRing(env, seat)) return;
    this.pendingFrom.add(env.from);
    this.arm();
  }

  onConnected(): void {
    this.arm();
  }

  private switchedOff(): boolean {
    return this.deps.envSwitchOff || this.deps.readState().switch === 'off';
  }

  hearing(): { hearing: Hearing; reason?: string } {
    if (this.switchedOff()) return { hearing: 'deaf', reason: 'switch-off' };
    if (this.deaf) return { hearing: 'deaf', reason: this.deaf };
    const p = this.deps.adapter().probe();
    return p.ready ? { hearing: 'idle' } : { hearing: 'deaf', reason: p.reason };
  }

  armed(): boolean {
    return this.hearing().hearing === 'idle';
  }

  private arm(): void {
    if (this.timer) return; // already coalescing: the burst becomes one line
    this.timer = this.setTimer(() => {
      this.timer = null;
      void this.fire();
    }, IDLE_COALESCE_MS);
  }

  private idle(state: IdleWakeState, now: number): boolean {
    if (this.deps.inFlight() > 0) return false;
    const { last_prompt_at: p, last_stop_at: s } = state;
    if (p !== undefined && (s === undefined || p > s)) return false; // a turn is running
    if (p !== undefined && now - p < IDLE_KEYBOARD_GUARD_MS) return false;
    const m = this.deps.transcriptMtime();
    return m === undefined || now - m >= IDLE_QUIET_MS;
  }

  private async fire(): Promise<void> {
    const senders = [...this.pendingFrom];
    this.pendingFrom.clear();
    if (this.switchedOff()) return;
    const state = this.deps.readState();
    const now = this.now();
    if (!this.idle(state, now)) return;
    const adapter = this.deps.adapter();
    if (!adapter.probe().ready) return;
    const res = await this.deps.check();
    if (res === null) return;
    if ('off' in res) {
      this.deaf = 'policy-off';
      return;
    }
    const recent = this.injects.filter((i) => now - i.at < HOUR);
    if (recent.length >= IDLE_SESSION_CAP_PER_HOUR)
      return this.deps.report({ act: res.act, outcome: 'capped', harness: adapter.harness, cap: 'session' });
    if (senders.some((f) => recent.filter((i) => i.from === f).length >= IDLE_SENDER_CAP_PER_HOUR))
      return this.deps.report({ act: res.act, outcome: 'capped', harness: adapter.harness, cap: 'sender' });
    const r = await adapter.inject(res.line);
    if (!r.ok) {
      this.deaf = r.reason;
      return this.deps.report({ act: res.act, outcome: 'failed', harness: adapter.harness, reason: r.reason });
    }
    for (const f of senders.length > 0 ? senders : ['(catch-up)']) this.injects.push({ at: now, from: f });
    this.deaf = null;
    this.deps.report({ act: res.act, outcome: 'injected', harness: adapter.harness });
    this.watchForTurn(now);
  }

  /** No transcript movement within 60 s of an ok inject → deaf until a later ready probe sees movement. */
  private watchForTurn(injectedAt: number): void {
    this.watch?.cancel();
    this.watch = this.setTimer(() => {
      const m = this.deps.transcriptMtime();
      if (m === undefined || m <= injectedAt) this.deaf = 'no-turn-after-inject';
    }, IDLE_DEAF_AFTER_MS);
  }
}
```
