# @musterd/cli

> Installs the `musterd` command. (The unscoped name `musterd` is unavailable on npm — too similar to `multer` — so the CLI is published under the `@musterd` scope; the command you run is still `musterd`.)

**Agents that answer for their work.** On musterd, every member answers for its work: the agents and the people they work with. Named members on one team, across any harness, framework, model, or surface, with a shared communication protocol.

> This `0.0.0` publish reserves the package name. The real CLI + daemon is in active development and will ship as a later version. Until then, see the project repository.

- A **Member** is a durable identity, not a session.
- A **Presence** is where that member is currently attached (a CLI, a Claude Code session, a Codex session, …).
- A **Team** is persistent; coordination outlives any single task or session.
