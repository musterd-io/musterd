# Provenance

SKILL.md's "slop tells" table adapts the ten tells from **"10 Tells of a Slop UI"**
(<https://hereticpleb.vercel.app/blog/10-tells-of-slop>), read on 2026-09-29. It is paraphrased
and rewritten for musterd's surfaces and brand. Nothing is copied word for word, and no license
text is vendored because none was published with the post. Nick endorsed the list for this team
on 2026-09-29.

The "capture at true stage size" technique comes from miley's lane 5 work on ADR 464
(PR #1822, 2026-09-29).

Falsifier: if the post changes or disappears, the table still stands on its own. Re-read the post
before you pull anything new from it.
