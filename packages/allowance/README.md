# @musterd/allowance

A local page of what is left on the provider accounts on this machine.

```bash
ELEVENLABS_API_KEY=… npx @musterd/allowance
```

Then open `http://127.0.0.1:4877`. The process binds to loopback. The key stays in the environment and is sent only to ElevenLabs. The page shows the character window and the voice slots when ElevenLabs reports them. OpenAI, Claude, OpenCode, Grok, Muse, Cursor, Hume and Exa are listed with the reason a number is absent.

`ALLOWANCE_PORT` chooses the port. Node 22 or newer.

From the musterd team. This page runs on its own. musterd is the team it comes from. [musterd.io](https://musterd.io)
